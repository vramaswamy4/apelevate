Writing your plan and checking it. This takes a few seconds…

How it works

  1. Code works out your weeks, the topics that exist, and which live classes fall in which week.
  2. An open-weights model (via Groq) turns that into a plan, as JSON that has to match a schema.
  3. Code checks every topic, class, week and hour. If the model broke a rule it gets one chance to fix it; if it still can't, you get an error instead of a wrong plan.

No free text goes to the model, only your choices on this form.
